```text
## 1. DESKRIPSI APLIKASI
NJIRLAH AI adalah platform chat multi‑model AI dengan dua sumber model:
- **OpenRouter** → WAJIB BYOK (pengguna memberikan API key miliknya, bisa yang gratis). Tanpa key, tidak bisa akses model OpenRouter.
- **Cloudflare Workers AI** → Token API disediakan server (bukan BYOK), selalu bisa digunakan tanpa key tambahan.

Terdapat dua halaman utama:
1. **Chat** (default, `/`) – chat dengan model AI, pilih model, lihat riwayat.
2. **Agent Code Generator** (`/agent`) – agen AI membangun proyek web lengkap, kode dihasilkan baris demi baris secara streaming, ditampilkan di IDE dengan syntax highlighting, dan pratinjau langsung di panel kanan.

## 3. ARSITEKTUR BACKEND (PROXY)
### 3.1 Proxy OpenRouter Chat (BYOK)
- File: `app/api/openrouter/chat/route.ts`
- Method: `POST`
- Menerima header `x-api-key` dari client.
- Meneruskan request ke `https://openrouter.ai/api/v1/chat/completions` dengan header `Authorization: Bearer [KEY]`.
- Dukung streaming (SSE); gunakan `ReadableStream` untuk meneruskan chunk demi chunk.
- **JANGAN PERNAH MENYIMPAN KEY DI SERVER**.

### 3.2 Proxy Cloudflare Workers AI Chat (Built‑in Token)
- File: `app/api/cloudflare/chat/route.ts`
- Method: `POST`
- Gunakan env `CLOUDFLARE_API_TOKEN` dan `CLOUDFLARE_ACCOUNT_ID`.
- Panggil `POST https://api.cloudflare.com/client/v4/accounts/{ACCOUNT_ID}/ai/run/{model}` dengan format body Cloudflare AI.
- Dukung streaming (SSE).

### 3.3 Agent Generate (Kode Proyek)
- File: `app/api/agent/generate/route.ts`
- Method: `POST`
- Body: `{ prompt, modelSource, modelId }`
- Header `x-api-key` untuk OpenRouter.
- Bangun system prompt yang memaksa LLM menghasilkan kode proyek web dengan format:
  ```
  ###FILE: nama_file.ext
  ```bahasa
  ... kode ...
  ```
- Kirim ke API LLM (OpenRouter/Cloudflare) dengan `stream: true`.
- Parsing stream real‑time untuk mendeteksi delimiter `###FILE:`.
- Kirim SSE events: `file_start`, `file_chunk`, `file_end`, `agent_log`, `done`, `error`.
- **Tidak boleh menyimpan key**; proxy saja.

### 3.4 Fetch Model Cloudflare (Server‑side)
- File: `app/api/cloudflare/models/route.ts`
- Method: `GET`
- Panggil `GET https://api.cloudflare.com/client/v4/.../ai/models?task=text-generation` dengan token server.
- Kembalikan daftar model.

## 4. ENKRIPSI KUNCI OPENROUTER
- File: `lib/encryption.ts`
- Gunakan Web Crypto API (AES‑GCM).
- Kunci enkripsi diturunkan dari **userAgent + screen width/height** (SHA‑256) + opsional **passphrase** (jika user set PIN).
- Fungsi: `encryptApiKey(plain)`, `decryptApiKey(cipher)`.
- Simpan ciphertext di localStorage; memory plaintext hanya di Zustand.

## 9. STATE MANAGEMENT (ZUSTAND)
Buat store:
- `useApiKeyStore`: `openrouterKey` (plaintext dari enkripsi), `setKey`, `clearKey`, `testConnection`.
- `useModelStore`: `openrouterModels`, `cloudflareModels`, `fetchModels`.
- `useChatStore`: chats, activeChat, addMessage, streaming.
- `useAgentStore`: files, activeFile, isGenerating, logs, actions untuk file events.
