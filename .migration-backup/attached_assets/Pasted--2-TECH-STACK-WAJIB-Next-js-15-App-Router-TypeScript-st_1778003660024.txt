## 3. ARSITEKTUR BACKEND
### Proxy OpenRouter (BYOK)
- `POST /api/openrouter/chat`
- Baca header `x-api-key` dari request client, teruskan ke `https://openrouter.ai/api/v1/chat/completions` dengan `Authorization: Bearer {key}`.
- Dukung streaming (SSE). Gunakan `ReadableStream` untuk meneruskan respons.
- **Jangan simpan key**.

### Proxy Cloudflare (built-in token)
- `POST /api/cloudflare/chat`
- Gunakan environment variable `CLOUDFLARE_API_TOKEN` dan `CLOUDFLARE_ACCOUNT_ID`.
- Panggil `https://api.cloudflare.com/client/v4/accounts/{ACCOUNT_ID}/ai/run/{model}` dengan format body Cloudflare Workers AI (`messages`).
- Dukung streaming juga.

## 4. ENKRIPSI KUNCI OPENROUTER (CLIENT-SIDE)
- Simpan di localStorage, enkripsi pakai AES-GCM (Web Crypto API).
- Kunci enkripsi turunan dari kombinasi unik browser (userAgent + screen). Jangan simpan plain text.

## 6. MODEL CLOUDFLARE (SERVER-SIDE FETCH)
- Fetch dari `GET https://api.cloudflare.com/client/v4/accounts/{ACCOUNT_ID}/ai/models?task=text-generation` menggunakan token server.
