## 🌐 1. NJIRLAH AI – DESKRIPSI UTAMA
NJIRLAH AI adalah platform chat multi‑model AI yang **WAJIB BYOK untuk OpenRouter**, dan **built‑in Cloudflare Workers AI** (token disediakan server).  
Dua sumber model:
1. **OpenRouter** → Pengguna **harus memasukkan API key miliknya sendiri** (bisa yang gratis). Tanpa key, tidak ada akses OpenRouter.
2. **Cloudflare Workers AI** → Menggunakan token API **milik NJIRLAH AI** (environment variable server), sehingga pengguna bisa langsung chatting dengan model Cloudflare tanpa memberikan kunci tambahan.

Branding: edgy, playful, premium – glassmorphism Tailwind + WebGL Unicorn.Studio + neon purple/cyan/pink.  
Nama: **NJIRLAH AI**. Tagline: “Chat AI Tersesat, Bebas Pake Kunci Sendiri”.

## 🔐 3. ARSITEKTUR & KEAMANAN
- OpenRouter API key **hanya disimpan di localStorage**, dienkripsi AES‑GCM (Web Crypto API) dengan passphrase turunan karakteristik browser.
- **Tidak ada API key OpenRouter di server**.
- Cloudflare token disimpan di environment variable `CLOUDFLARE_API_TOKEN` dan `CLOUDFLARE_ACCOUNT_ID` di server. **Tidak dikirim ke klien**.

### Proxy API routes:
- `POST /api/openrouter/chat`  
  → Membaca header `x-api-key` dari request klien, meneruskan `Authorization: Bearer {key}` ke `https://openrouter.ai/api/v1/chat/completions`. **Tidak menyimpan key**.
- `POST /api/cloudflare/chat`  
  → Menggunakan token server, meneruskan request ke `https://api.cloudflare.com/client/v4/accounts/{ACCOUNT_ID}/ai/run/@cf/model`.  
  → Body request mengikuti format Cloudflare Workers AI (messages).

Kedua endpoint wajib mendukung **streaming (SSE)** dengan `ReadableStream`.

## ☁️ 5. CLOUDFLARE WORKERS AI (BUILT‑IN, BUKAN BYOK)
- Token Cloudflare disimpan di server (`CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`).
- Model Cloudflare **selalu tersedia** tanpa syarat.
- Fetch daftar model text‑generation dari  
  `GET https://api.cloudflare.com/client/v4/accounts/{ACCOUNT_ID}/ai/models?task=text-generation`  
  (gunakan token server di server side, jangan expose ke klien).
- Model Cloudflare ditampilkan di ModelSelector dengan ikon “CF”.
- Endpoint proxy `/api/cloudflare/chat` menangani request sesuai format Cloudflare AI.
